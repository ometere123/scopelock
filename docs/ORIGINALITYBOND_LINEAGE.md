# OriginalityBond lineage

OriginalityBond was a reusable semantic-originality primitive. Its first submission was rejected because tracked test candidates were treated as GenVM source and failed unresolved pytest/conftest imports—not because its core mechanism was trivial.

ScopeLock preserves the deterministic, append-only vector precedent-discovery idea, but changes the product boundary completely: immutable security programs, public evidence, scoped duplicate checking, severity adjudication, GEN bounty escrow, and deterministic settlement. Git history retains the original work; this repository has one intentional contract candidate and an automated candidate audit so the source-check failure is directly remediated.
